👔 Вход для директора 📋 Вход для бухгалтера 👷 Вход для работника
❓ Руководство по WMS «Ремера»
Дашборд — учебная база для тренировок. Чат — живая отчётность цеха. У каждой роли свой PIN и свои возможности.
👷 Работник — сдаёт рапорт
  1. Нажми 💬 Чат → «Вход для работника» → введи свой PIN.
  2. Набери команду и нажми ➤. Ответ придёт мгновенно.
/расход 5 PA-F — выдал 5 бобин в производство
/приход 10 PA-F — принял 10 бобин от поставщика
/отгрузка 3 PP-16 — отгрузил 3 клиенту
/производство 20 STAT-10 — сплёл 20 готовой продукции
/коды — список кодов · /список — все команды
👔 Директор — согласует проводки
  1. Нажми 💬 Чат → «Вход для директора» → свой PIN.
  2. Жёлтая карточка сверху — рапорт работника, ждёт решения.
  3. Провести — операция встанет в журнал, остатки изменятся.
    Отклонить — рапорт отменён, остатки не тронуты.
  4. Вкладки «Остатки» и «Журнал» — текущая картина склада.
📋 Бухгалтер — сверяет с 1С
  1. Нажми 💬 Чат → «Вход для бухгалтера» → свой PIN.
  2. Открыты «Остатки» и «Журнал» — только чтение, без поля ввода.
📦 Обмен с 1С (учебная БД)
  1. 📥 CSV: 1С (остатки) — загрузить начальные остатки из 1С.
  2. 📄 CSV: Склад / Движения — выгрузить данные для бухгалтера.
🔐 PIN выдаёт директор. Ошибся в PIN — система попросит ввести снова и не пустит в чужую роль.
